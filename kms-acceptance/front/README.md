# kms-acceptance front

Demo 管理端验收测试台，按八项验收标准展示结果。性能和攻击用例可从管理端触发，预分配吞吐由节点侧采集后录入。

## 启动

```bash
npm install
npm run dev
```

## 当前配置

1. 默认前端端口：`5176`
2. 开发环境将 `/acceptance-api` 代理到 `http://127.0.0.1:9090`
3. 生产构建基路径为 `/acceptance/`
4. 页面默认展示八项指标：无证书生成 > 10 万 TPS、预分配 > 50 条/秒、更新 ≥ 5000 TPS、异常回收 ≥ 5000 TPS、回收率 > 98%、生成攻击 ≥ 3 类、量子威胁模拟 ≥ 3 类、网络攻击 ≥ 5 类
