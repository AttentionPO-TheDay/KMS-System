

### 启动

**1. 启动ganache**
```bash
任意终端
npx ganache
```

**2. 启动后端服务**
```bash
cd backend
python manage.py runserver 127.0.0.1:8000
```
**3. 启动前端服务**
```bash
cd web
npm run dev
```

## 📡 API使用示例

### 1. 系统初始化
```bash
curl -X POST http://127.0.0.1:8000/api/pqkds/blockchain/setup/ \
  -H "Content-Type: application/json" \
  -d '{
    "provider_url": "http://localhost:8545",
    "contract_address": "",
    "private_key": ""
  }'
```

### 2. 注册节点
```bash
curl -X POST http://127.0.0.1:8000/api/pqkds/blockchain/register-node/ \
  -H "Content-Type: application/json" \
  -d '{
    "node_id": "test_node_001",
    "name": "测试节点001",
    "ip_address": "192.168.1.100",
    "port": 8080
  }'
```

### 3. 获取节点密钥
```bash
curl http://127.0.0.1:8000/api/pqkds/blockchain/nodes/test_node_001/keys/
```

### 4. 验证密钥完整性
```bash
curl -X POST http://127.0.0.1:8000/api/pqkds/blockchain/verify-integrity/ \
  -H "Content-Type: application/json" \
  -d '{
    "node_id": "test_node_001"
  }'
```

## 🛠️ 开发模式

### 启动开发服务器
```bash
cd backend
python manage.py runserver 0.0.0.0:8000 --settings=application.settings
```

### 数据库管理
```bash
# 创建迁移
python manage.py makemigrations

# 执行迁移
python manage.py migrate

# 创建超级用户
python manage.py createsuperuser

# 访问管理界面# http://127.0.0.1:8000/admin/
```

### 清理数据库
```bash
# 删除数据库文件
rm db.sqlite3

# 重新创建数据库
python manage.py migrate
```

## p

### 常见问题

**1. 端口被占用**
```bash
# 查找占用8000端口的进程
netstat -ano | findstr :8000  # Windows
lsof -i :8000                 # Linux/Mac

# 杀死进程
taskkill /PID <PID> /F        # Windows
kill -9 <PID>                 # Linux/Mac
```

**2. 依赖包缺失**
```bash
# 安装所有依赖
pip install -r requirements.txt

# 或者单独安装
pip install django djangorestframework numpy cryptography web3
```

**3. 数据库错误**
```bash
# 重置数据库
rm db.sqlite3
python manage.py migrate
```

**4. 密钥生成失败**
```bash
# 运行调试脚本
python debug_falcon_generation.py

# 检查系统参数
python check_system_params.py
```
