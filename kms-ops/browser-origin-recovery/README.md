# 恢复原浏览器入口

2026-10-20 更新：服务器已恢复为 `10.112.125.22`，网址为 `https://10.112.125.22:8443/updatedel/demo`，启动器直连该地址，不再转发到 `10.129.114.144`。
继续保留原来的浏览器 origin，可读取原 Chrome 配置中该站点的 IndexedDB。现有证书仍有效，无须重新安装。

1. 双击桌面“KMS旧入口恢复”快捷方式或 `open-old-origin.cmd`，一次打开节点A、节点B、节点C三个窗口，分别使用原来的 Profile 5、Profile 6、Profile 7。
2. 若已有Chrome由此恢复入口启动，可直接复用；若提示先退出Chrome，请保存未完成的操作，在地址栏输入 `chrome://quit`，退出后继续。
3. 若提示证书安装，在打开的证书窗口选择：安装证书 → 当前用户 → 将所有证书放入下列存储 → 受信任的根证书颁发机构。启动后各窗口地址栏应仍是旧 IP。

启动器不新建浏览器配置，不修改或搬移 IndexedDB，不生成新节点密钥，不改变系统代理；
它保留当前静态系统代理，并仅让新旧 KMS IP 直连。映射只在本次启动的 Chrome 进程中生效。
已有Chrome未带恢复映射时，需要先退出再启动；带恢复映射的Chrome可同时承载三个原配置，各配置的站点资料仍相互独立。
